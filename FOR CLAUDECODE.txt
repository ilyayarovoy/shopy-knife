Изменение структуры БД и API
Сейчас твоя схема (например, в SQLAlchemy, Tortoise или Django ORM) выглядит примерно так: image_url = String. Тебе нужно дать возможность хранить несколько ссылок.

Есть два пути, выбирай в зависимости от СУБД:

Вариант А: Если используешь PostgreSQL (Рекомендуемый)
PostgreSQL отлично умеет работать с массивами прямо из коробки. Ты можешь просто изменить тип поля на ARRAY.

Модель БД: images = Column(ARRAY(String))

Что отдавать в API (JSON):

{
  "id": 1,
  "title": "Нож 'Охотник'",
  "images": [
    "https://res.cloudinary.com/demo/image/upload/v1/photo1.jpg",
    "https://res.cloudinary.com/demo/image/upload/v2/photo2.jpg"
  ]
}
